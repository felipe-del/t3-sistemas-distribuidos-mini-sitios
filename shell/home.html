📚 Biblioteca Virtual

Aplicación compuesta por un shell que integra cuatro mini-sitios independientes, cada uno con su propio backend:

  • Libros (JavaScript vanilla + fetch)
  • Autores (Vue 3)
  • Editoriales (React)
  • Reseñas (JavaScript vanilla + fetch) — mini-sitio nuevo (ejercicio 2)

Cada mini-sitio se carga dentro de un iFrame y puede navegarse de forma independiente.
